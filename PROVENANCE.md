# Provenance

`OFD-SignedInt4` isolates representation-level claims from the broader OFD line. Historical OFD code or measurements are not evidence here unless imported with source repository, commit SHA, path, and semantic compatibility note.

Durable artifacts should distinguish researcher derivation, assistant synthesis, measured result, and external fact/source. Assistant-authored prose is not itself evidence.

Integration evidence from DirectK or DirectV must record the exact upstream commit SHA and whether the representation contract was revalidated locally.
