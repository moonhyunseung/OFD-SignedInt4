# Theory workspace

This directory is for exact representation algebra.

Planned topics:

- offset-binary and two's-complement code spaces;
- code bijections and decoder commutation;
- packed-byte recoding;
- signed/unsigned radix decompositions;
- coordinate/group permutations;
- representation automorphisms under fixed scales/grouping;
- operator compatibility with DirectK/DirectV.

Every proposed automorphism must state the frozen representation contract it preserves.
