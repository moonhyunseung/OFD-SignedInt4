# Analysis

Representation claims should be resolved by exact algebra or finite exhaustive verification before statistical analysis.

Hardware analysis begins only after representation equivalence is closed.

Required practice:

- preserve exhaustive nibble/byte tables as primary evidence;
- distinguish representation-validity results from hardware-benefit results;
- compare offset, inline-recode, materialized-recode, and native-signed paths under identical quantized semantics;
- tie all hardware conclusions to manifests and raw measurements;
- retain negative results that rule out a representation path on a target architecture.
