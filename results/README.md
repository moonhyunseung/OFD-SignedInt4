# Results

Representation-validity results should preserve exhaustive artifacts directly.

Recommended structure:

```text
results/E00_nibbles/
  manifest.json
  nibble_table.csv
  summary.md
results/E01_bytes/
  manifest.json
  byte_table.csv
  summary.md
```

Later hardware results use the same manifest/raw/derived/summary pattern as the operator repositories.

Every summary distinguishes exact finite verification from hardware interpretation.
